# FOOD_STORE
# Programación II

Sistema de consola para administrar categorías, productos, usuarios y pedidos con Python y POO.

## Requisitos
- Python 3.12 o superior.
- No requiere bibliotecas externas.

## Ejecución
Desde la carpeta `food_store`:

```
python main.py
```

## Administrador inicial
- Mail: `admin@foodstore.com`
- Contraseña: `admin123`

## Pruebas del modelo y servicios

```
python pruebas.py
```

## Organización
- `entidades`: clases del modelo.
- `enums`: enumerados del sistema.
- `excepciones`: excepciones propias.
- `servicios`: lógica de negocio y colecciones.
- `consola`: menús y lectura de datos.
- `main.py`: inicialización y ciclo de sesión.

Los datos se mantienen en memoria durante la ejecución y se pierden al cerrar el programa, tal como indica la consigna.
